### Convenções para nomes de arquivos

* Use **letras minúsculas apenas**
* Separe palavras com **underscore (`_`)**, se necessário
* Evite nomes muito longos ou confusos
* O nome do arquivo deve ser **válido como identificador Python**

#### Exemplos corretos:

```python
meu_modulo.py
processamento_dados.py
utils.py
calculadora_financeira.py
```

#### Exemplos incorretos:

```python
MeuModulo.py        # usa maiúsculas
processamento-Dados.py  # usa hífen (inválido em Python)
123modulo.py        # começa com número
meu modulo.py       # espaço não permitido
```

---

### Dicas práticas

* Prefira nomes **curtos e descritivos**
* Evite abreviações obscuras
* Use nomes que indiquem claramente o propósito do arquivo
