# ATIVIDADE – INTRODUÇÃO AO PROJETO DE APLICAÇÕES WEB

**1.** O que você entende por uma aplicação web? Cite dois exemplos de aplicações web que você utiliza no seu dia a dia.

**2.** Pense em um problema do cotidiano que poderia ser resolvido por meio de uma aplicação web. Qual seria esse problema?

**3.** Qual seria o principal objetivo da aplicação que você imaginou na questão anterior?

**4.** Por que você considera importante planejar uma aplicação antes de começar a escrever o código?

**5.** O que pode acontecer quando uma aplicação é desenvolvida sem um planejamento adequado?

**6.** Imagine que você precisa criar um sistema escolar para uma escola. Quais necessidades dos alunos, professores ou funcionários deveriam ser identificadas antes do desenvolvimento?

**7.** Explique, com suas palavras, o que acontece quando um usuário acessa uma aplicação web pelo navegador.

**8.** Qual é a função do cliente e qual é a função do servidor na arquitetura cliente-servidor?

**9.** Por que uma URL é importante para acessar uma aplicação ou recurso na internet?

**10.** Qual é a principal diferença entre HTTP e HTTPS? Por que a segurança é importante durante o acesso a uma aplicação web?

**11.** Imagine que você está utilizando um aplicativo de compras. Dê um exemplo de uma função que poderia fazer parte do **front-end** e outra que poderia fazer parte do **back-end**.

**12.** Qual é a função do HTML, do CSS e do JavaScript no desenvolvimento front-end?

**13.** Por que o front-end e o back-end precisam se comunicar em uma aplicação web?

**14.** Qual é a função de uma API nessa comunicação?

**15.** Observe a seguinte situação:

> Um aluno acessa um sistema escolar pelo navegador para consultar suas notas.

Descreva, com suas palavras, o caminho que uma solicitação desse aluno pode percorrer até que as notas sejam apresentadas na tela.

**16.** Na sua opinião, qual etapa é mais importante no desenvolvimento de uma aplicação web: entender o problema, planejar, desenvolver, testar ou manter? Justifique sua resposta.

**17.** Imagine que você recebeu a tarefa de desenvolver uma aplicação para resolver um problema da sua escola. Qual seria a primeira coisa que você faria antes de começar a programar?

**18.** Complete a frase com sua própria reflexão:

**“Antes de programar uma aplicação web, é importante __________________________ porque __________________________.”**

**19.** O que você aprendeu nesta aula que mudou ou ampliou sua visão sobre o desenvolvimento de aplicações web?

**20.** Para finalizar: **antes de escrever qualquer código, qual problema você gostaria de resolver com uma aplicação web e por quê?**
