# LINGUAGEM DE MARCAÇÃO — HTML

## 1. HTML

**HTML — HyperText Markup Language**

→ Linguagem de **marcação de hipertexto**
→ Utilizada para criação de **documentos web**

### Documento de texto × documento de hipertexto

**Documento de texto:**

* Livro
* Folha de papel impressa

**Documento de hipertexto:**

* Links → permitem acessar outros documentos
* Imagens interativas
* Vídeos
* Áudios
* Outros recursos

---

## 2. DOCUMENTOS WEB

Documentos web podem ser acessados pela **internet** por meio de um:

### NAVEGADOR / BROWSER

Exemplos:

* Chrome
* Firefox
* Edge
* Opera
* Safari

**Navegadores:**

→ Permitem acessar websites
→ Websites estão hospedados em **servidores na internet**

---

## 3. URL

Ao digitar um endereço de **URL** no navegador:

**URL = Uniform Resource Locator**

→ "localizador uniforme de recursos"

```text
USUÁRIO
   ↓
DIGITA A URL
   ↓
NAVEGADOR
   ↓
WEBSITE
   ↓
PÁGINA WEB
```

A página é exibida **devidamente formatada** pelo navegador.

---

## 4. CÓDIGO-FONTE HTML

Por trás de uma página web existem elementos organizados.

O **código-fonte** é escrito em **HTML**.

Cada elemento:

→ textual
→ gráfico

pode ser representado por meio de **TAGS**.

### TAGS

→ Compõem a **estrutura dos documentos web**.

---

# HISTÓRIA DO HTML

## 5. ORIGEM

**Início dos anos 1990**

**Tim Berners-Lee**

Trabalhava no:

**CERN — Organização Europeia para a Pesquisa Nuclear**

HTML foi inspirado inicialmente pela:

**SGML — Standard Generalized Markup Language**

→ Metalinguagem criada pela IBM nos anos 1960
→ Utilizava tags para estruturar elementos

### Objetivo inicial do HTML

→ Permitir o **compartilhamento de informações** entre pesquisadores em universidades.

**1995**

→ HTML compartilhado com o nome de **HTML 2.0**

---

## 6. WORLD WIDE WEB

**Tim Berners-Lee** também propôs o:

**WorldWideWeb**

→ Primeiro navegador de internet

### WWW

**WorldWideWeb**

→ "rede mundial de computadores"

---

# EVOLUÇÃO DO HTML

## 7. W3C

**1996**

**W3C — World Wide Web Consortium**

→ Passa a coordenar o desenvolvimento do HTML
→ Padroniza e organiza suas versões futuras

---

## 8. HTML 4.01

**1999**

→ Lançamento oficial do **HTML 4.01**

### Principais características:

* Grandes melhorias estruturais
* Fortaleceu o uso de **folhas de estilo (CSS)**
* Separou **forma e conteúdo**

---

## 9. HTML5

**2014**

→ Lançamento oficial do **HTML5**

Desenvolvimento iniciado em meados dos anos 2000.

### HTML5 — A revolução da Web

Introduziu avanços importantes:

* Novas tags semânticas:

  * `<header>`
  * `<nav>`
  * `<section>`
  * `<footer>`
* Suporte nativo a multimídia
* Sintaxe mais limpa e simplificada
* Reforço da multimídia
* Interatividade
* Acessibilidade

---

# 10. CONCLUSÃO

**HTML**

→ Evoluiu de uma linguagem estruturada simples

→ Para uma ferramenta poderosa

→ Que define o **conteúdo e a estrutura da Web moderna**.
