# Questões Discursivas e Argumentativas — Introdução às APIs

**Curso:** Técnico em Informática para Internet
**Capítulo 1:** Introdução às APIs

## Orientações

Responda às questões de forma **clara, completa e argumentativa**. Sempre que possível, utilize exemplos do cotidiano, de sites ou de aplicações web para justificar sua resposta.

---

### Questão 1 — Conceito de API

Explique, com suas próprias palavras, o que é uma API e qual é sua importância para a comunicação entre diferentes sistemas de software.

Em sua resposta, apresente um exemplo prático de uma situação em que dois sistemas precisam se comunicar por meio de uma API.

---

### Questão 2 — API como ponte de comunicação

Uma API pode ser comparada a uma "ponte" entre sistemas.

Explique essa comparação e argumente por que uma aplicação não precisa necessariamente conhecer todos os detalhes internos do sistema com o qual está se comunicando.

---

### Questão 3 — Cliente e servidor

Considere a seguinte situação:

> Um usuário acessa um site de previsão do tempo e informa a cidade "Timon". O site apresenta a temperatura atual e outras informações meteorológicas.

Explique, nesse cenário:

1. Quem pode ser considerado o cliente?
2. Qual sistema pode atuar como servidor?
3. Qual seria a função da API?
4. O que poderia ser enviado na requisição?
5. O que poderia ser recebido na resposta?

### Questão 4 — API no comércio eletrônico

Uma loja virtual precisa realizar pagamentos, mas a empresa não deseja desenvolver internamente todo o sistema financeiro responsável pelo processamento das transações.

Explique como uma API de pagamentos poderia solucionar esse problema.

Argumente sobre **duas vantagens** de utilizar um serviço externo por meio de uma API nesse cenário.

### Questão 5 — APIs públicas e inovação

Apresente um exemplo para justificar sua resposta.

### Questão 8 — APIs e Segurança da Informação

### Questão 9 — Autenticação x autorização

Depois, utilize o seguinte exemplo para justificar sua resposta:

Explique onde ocorre autenticação e onde ocorre autorização nessa situação.

## Orientação para o aluno

Uma boa resposta discursiva **não deve apenas definir o conceito**.

Procure seguir esta estrutura:

```text
1. Apresente sua ideia;
2. Explique o conceito;
3. Relacione com a situação apresentada;
4. Apresente um exemplo;
5. Justifique sua conclusão.
```

### Exemplo de estrutura de resposta

> **"Uma API é importante porque permite que sistemas diferentes troquem informações de maneira padronizada. Por exemplo, uma loja virtual pode utilizar uma API de pagamentos para enviar os dados necessários ao serviço financeiro e receber como resposta a confirmação da transação. Dessa forma, a empresa não precisa desenvolver todo o sistema financeiro internamente, reduzindo a complexidade da aplicação e facilitando a integração com serviços especializados."**
